# Injection Security Audit — AlUmmahNowApple

| Component | Input | Risk | Status | Test |
| --- | --- | --- | --- | --- |
| `AppLink.parse` (`AUNCoreBridge`) | Universal link URL (`user`/`password`, `..`, `%2e%2e`, `@..`, studio `channelID`) | Authority/userinfo spoofing and path traversal segments forwarded to API routes | Fixed — rejects userinfo, control chars, dot/percent-encoded traversal segments, and validates IDs/handles/channelIDs with `SafeInput.isSafePathSegment` | `AUNCoreBridgeTests/InjectionAuditTests.swift::appLinkRejectsUserinfoAndTraversalSegments` |
| `ShortLinks.shortLinkOriginFor` (`AUNCoreBridge`) | `siteHostOrOrigin` | Hostname / userinfo injection into generated share URLs | Fixed — rejects userinfo and enforces `SafeInput.isSafeHostname` | `AUNCoreBridgeTests/InjectionAuditTests.swift::shortLinksRejectInvalidHostnameAndUserinfo` |
| `NativeCatalogService` (`AUNCoreBridge`) | `video(id:)`, `subtitles(videoID:)`, `chapters(videoID:)`, `subtitleText(url:)` | Path traversal via interpolated IDs; arbitrary URL scheme (`file://`, cleartext `http://`) fetch in `subtitleText` | Fixed — validates path segments, resolves via `SafeInput.resolveSameOrigin`, enforces `SafeInput.isSafeNetworkURL` on `subtitleText` | `AUNCoreBridgeTests/InjectionAuditTests.swift::catalogServiceBlocksPathTraversalAndUnsafeSubtitleURL` |
| `NativeLiveService` (`AUNCoreBridge`) | `stream/state/chat/chatReplay/beat(id:)` | Path traversal via raw `id` interpolation into `/api/live-streams/\(id)` | Fixed — validates `id` with `SafeInput.isSafePathSegment` and resolves via `SafeInput.resolveSameOrigin` | `AUNCoreBridgeTests/InjectionAuditTests.swift::liveServiceBlocksPathTraversal` |
| `NativeStudioService` & `StudioHTTPClient` (`AUNCoreBridge`) | `channelID`, `videoID`, `id`, `playlistID`, `channelId` header | Path traversal via raw ID interpolation; header injection in `channelId`; origin escape | Fixed — validates all dynamic path segments (`checkedSegment`), validates paths via `SafeInput.resolveSameOrigin`, rejects control chars in `channelId` header | `AUNCoreBridgeTests/InjectionAuditTests.swift::studioServiceBlocksPathTraversalAndHeaderInjection` |
| `PrivateMediaSession` (`NoStoreDelegate`) & `NativeReviewService` (`AUNCoreBridge`) | HTTP 3xx redirects; `adminAPI`/`videosAPI` base URLs | Cross-origin or cleartext redirect leaking `Authorization` / `X-AUN-Native-Proof`; non-HTTP scheme accepted for `localhost` (e.g. `ftp://localhost`) | Fixed — `NoStoreDelegate` refuses cross-origin/insecure redirects; `NativeReviewService.send` uses `SafeInput.resolveSameOrigin` | `AUNCoreBridgeTests/InjectionAuditTests.swift::reviewServiceRejectsInsecureBaseScheme` |
| `NativeTUSUploadEngine` & `TUSTransfer` (`AUNCoreBridge`) | `endpoint`, `resumeURL`, server `Location`, `metadata` keys, custom headers | SSRF/credential leakage to cross-origin or cleartext TUS `Location`/`resumeURL`; `Upload-Metadata` key injection; reserved/CRLF header injection | Fixed — enforces `isSafeNetworkURL` + `sameOrigin` on `Location` and `resumeURL`, validates `Upload-Metadata` keys, blocks reserved/CRLF headers | `AUNCoreBridgeTests/InjectionAuditTests.swift::tusUploadAndTransferRejectCrossOriginLocationAndBadMetadataKeys` |
| `NativeEncodePlanner` (`AUNCoreBridge`), `PreEncoder`, `RenditionUploader`, `UploadView.copyIntoContainer` (`AUNStudio`) | Source filename, `preset.name`, `rung.name`, `StagedFile.path` | Path traversal outside working/output/container directories | Fixed — sanitizes filenames via `SafeInput.sanitizeFileName`, validates `rung.name`, enforces `SafeInput.resolveContainedFile` (including symlink resolution) | `AUNCoreBridgeTests/InjectionAuditTests.swift::encodePlannerAndContainedFileRejectTraversal`, `AUNStudioTests/InjectionAuditTests.swift::renditionUploaderBlocksPathTraversalOutsideRoot` |
| `CSVWriter.field` (`AUNStudio`) | Exported analytics titles/cells with leading whitespace or `\n` before `=`, `+`, `-`, `@` | Spreadsheet CSV formula injection | Fixed — detects formula triggers at start and after leading whitespace/newlines (while preserving finite negative numbers) | `AUNStudioTests/InjectionAuditTests.swift::csvWriterNeutralizesLeadingWhitespaceAndNewlineFormulas` |
| `PlayerSurface` & `SubtitleOverlay` (`AUNPlayer`) | External URL passed to `SFSafariViewController` / `openURL` | Crash (`SFSafariViewController` on non-http(s)) or unsafe scheme launch | Fixed — guarded with `SafeInput.isSafeExternalURL` | `AUNCoreBridgeTests/InjectionAuditTests.swift::safeExternalURLAndLogSanitizerWork` |
| `ViewerReportURL` (`AUNFeatures`) & `AppEnvironment.webBaseURL` (`AUNCoreBridge`) | `webBaseURL`, `apiBaseURL` host | Unsafe scheme (`javascript:`, `http://`) or userinfo in report URLs | Fixed — forces `https://` (or loopback `http://`), strips userinfo, validates hostnames | `AUNFeaturesTests/InjectionAuditTests.swift::viewerReportURLRejectsUnsafeBaseSchemeAndUserinfo` |
| `AUNLog` call sites (`NativeCatalogService`, `NativeLiveService`) | Logged request paths | Log injection via control/newline characters | Fixed — `SafeInput.sanitizeLogLine` applied to dynamic paths; Apple `os.Logger` structured logging keeps error/private values redacted by default | `AUNCoreBridgeTests/InjectionAuditTests.swift::safeExternalURLAndLogSanitizerWork` |
| `WebVTT.parse` (`AUNPlayer`) | Server subtitle text | Rendered in SwiftUI `Text` (plain text, no WebView/HTML engine); strips `<...>` tags | OK — no HTML/JS execution surface | Existing `AUNPlayerTests` |
| `CoreAccountService` & `SystemWebAuthenticator` (`AUNCoreKit`, `AUNStudio`) | OAuth PKCE flow & callbacks | Open redirect / CSRF / session sharing | OK — ephemeral `ASWebAuthenticationSession` with custom callback scheme; PKCE + state verified by `aun-auth` in `AlUmmahNowCore` | Existing `AUNCoreKitTests` / `AUNStudioTests` |
| `AdminRootView.open` & `AdminPush.handle` (`AUNAdmin`) | `alummahnow-admin://` deep links & APNs `userInfo["reviewId"]` | Path traversal / injection via `reviewId` | OK — validated with `ReviewID.isValid` (`[A-Za-z0-9_-]{1,64}`) before use | Existing `AUNAdminTests` |
| WebViews / SQLite / Child Processes | N/A | N/A | OK — no `WKWebView`, no raw SQLite/GRDB queries, no `Process` shell invocations in app code | Codebase audit |
