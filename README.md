# AlUmmahNowApple

Al Ummah Now native Apple apps in Swift and SwiftUI: viewer and Studio for iOS, iPadOS, tvOS and macOS.

```sh
brew install xcodegen
make generate
open AlUmmahNow.xcworkspace
```

See [docs/PLAN.md](docs/PLAN.md), [docs/OWNER_INPUTS.md](docs/OWNER_INPUTS.md) and [CLAUDE.md](CLAUDE.md).
